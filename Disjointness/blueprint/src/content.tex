\section{What is checked}
The full BJKS conditional-information argument is checked. The explicit
communication bound is $n/(144\log 2)$ bits at worst-case error $1/3$.
The finite model, reachable-length normalization, and arbitrary measurable
random-tape extension all have kernel-checked proofs.

Select a node in the dependency graph and follow its Lean link to the API.
The exact model and audit boundaries are recorded in \texttt{docs/audit.md}.
The output is a public leaf label; translations from other machine syntax or
a private-output convention are not included.
