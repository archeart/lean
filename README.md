# Lean experiments

Experiments in AI-assisted mathematical formalization using Lean, with human auditing of the mathematical statements, proofs, and development process.

## Projects

- [Disjointness](Disjointness/README.md): formalize the information-complexity proof of the randomized communication lower bound for set disjointness. The project currently contains its phased implementation and audit plan.

Each project will document its own Lean toolchain, dependencies, build instructions, and verified results as implementation proceeds.
